# Pokedex
Diese Applikation ermöglicht es Ihnen, all Ihre Lieblingspokemons zu entdecken.

## Verwendung
1. Nach Pokemon suchen
- Über das Eingabefeld (oben rechts) kann nach Pokemons gesucht werden, dabei müssen mindestens 3 Buchstaben geschrieben werden, damit ein Pokemon gefunden werden kann.
2. Neue Pokemon laden
- Über den "load more" - Button können zusätzliche Pokemon geladen werden
